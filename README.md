# Multi Tool

All-in-one Termux CLI tool to manage **GitHub · Vercel · Netlify · Supabase · Telegram** — easy to easy.

## Install

```bash
curl -sL https://raw.githubusercontent.com/qutexora62/Multi-Tool/main/install.sh | bash
```

## Run

```bash
multitool
```

## Menu

```
1) GitHub
2) Vercel
3) Netlify
4) Supabase
5) Telegram
0) Exit
```

## Uninstall

```bash
curl -sL https://raw.githubusercontent.com/qutexora62/Multi-Tool/main/uninstall.sh | bash
```
