# Multi-Tools

All-in-one Termux CLI tool to manage **GitHub · Vercel · Netlify · Supabase · Telegram** — easy to easy.

**Author:** Dr. @cutexora

## Install

```bash
curl -s -H "Accept: application/vnd.github.raw" "https://api.github.com/repos/qutexora62/Multi-Tool/contents/install.sh" | bash
```

> Uses the GitHub API to always fetch the latest installer (bypasses raw CDN cache).

## Run

```bash
multitool
```

## Menu

```
1) GitHub
2) Vercel
3) Netlify
4) Supabase
5) Telegram
0) Exit
```

## Uninstall

```bash
curl -s -H "Accept: application/vnd.github.raw" "https://api.github.com/repos/qutexora62/Multi-Tool/contents/uninstall.sh" | bash
```
